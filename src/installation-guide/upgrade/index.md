# Upgrade

Instructions for upgrading from previous versions of NADA. Use the guide that matches your **current** version.

**Latest documented target:** [Upgrade to 5.6](/installation-guide/upgrade/upgrade-56)

| From → To | Guide |
|-----------|-------|
| 5.5.x → 5.6 | [Upgrade to 5.6](/installation-guide/upgrade/upgrade-56) |
| 5.4.x → 5.5 | [Upgrade to 5.5](/installation-guide/upgrade/upgrade-55) |
| 5.x → 5.4 | [Upgrade to 5.4](/installation-guide/upgrade/upgrade-54) |
| 5.x → 5.2 | [Upgrade to 5.2](/installation-guide/upgrade/upgrade-52) |
| 4.4 → 5.0 | [Upgrade to 5.0](/installation-guide/upgrade/upgrade-50) |
| 4.3 → 4.4 | [Upgrade to 4.4](/installation-guide/upgrade/upgrade-44) |
| → 4.3 | [Upgrade to 4.3](/installation-guide/upgrade/upgrade-43) |
| 4.x → 4.2 | [Upgrade to 4.2](/installation-guide/upgrade/upgrade-42) |
| 3.x → 4.0 | [Upgrade to 4.0](/installation-guide/upgrade/upgrade-40) |

When upgrading across multiple versions, apply each guide in sequence (for example 5.4 → 5.5 → 5.6).

Guides for NADA **4.x and earlier** are kept for legacy catalogs; prefer upgrading to a supported 5.x release for new work.
