# Configurations

After NADA is installed, configure the catalog so curators can publish content and users can register, request data, and receive notifications.

| Topic | Page |
|-------|------|
| Email (basic) | [Email](./email) |
| Email (SMTP, SendGrid, troubleshooting) | [Email (advanced)](./email-advanced) |
| Captcha (login / registration) | [Captcha](./captcha) |
| Google Analytics | [Google Analytics](./google-analytics) |
| Themes (header, footer, CSS) | [Customizing themes](./customizing-themes) |
| Clean URLs (Apache) | [Clean URLs](./clean-urls) |
| Content Security Policy | [CSP](./csp) |

Site-level options in the admin UI (title, home page, menus) are covered under [Site administration](/admin-guide/web-ui/) and [Site configurations](/admin-guide/web-ui/site-configurations).

::: tip Suggested order
1. [Email](./email)  
2. [Captcha](./captcha) if the site allows public registration  
3. Optional: analytics, themes, clean URLs, CSP  
:::
