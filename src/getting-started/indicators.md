# Getting started with indicators & time series

NADA publishes **indicators** and **time series** with their data: each indicator gets a catalog page with its documentation, an interactive chart, a data table, downloads and a data API.

## Try it

The fastest way to learn is the [tutorial](/admin-guide/content/indicators-tutorial). In about 20 minutes you publish the World Bank indicator **SI.POV.DDAY** (*Poverty headcount ratio at $3.00 a day*), for 183 countries, using the sample files in [try_indicators.zip](https://github.com/ihsn/nada-documentation/raw/main/examples/indicators/try_indicators.zip).

You need NADA 5.6 or later with [MongoDB](/installation-guide/installation-mongodb) set up.

::: tip Recommended order
If you are new to NADA, complete the [microdata](./microdata) tutorial first so you are familiar with login, publishing, and drafts. Then return here for indicators.
:::
