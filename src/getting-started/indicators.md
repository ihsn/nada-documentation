# Getting started with indicators & time series

NADA can catalog **indicators** and **time series**, with optional charts, data download, and API access.

There is no separate “try_indicators” sample package in this repository yet. Use these paths:

1. **Admin UI** — Create an indicator project, attach a data structure (DSD), and upload CSV data: [Indicators — Admin UI](/admin-guide/content/indicators-admin).
2. **What users see** — Series description, chart & data, downloads: [Indicators — Catalog frontend](/admin-guide/content/indicators-frontend).
3. **Full publishing reference** (including API examples): [Publishing indicators](/admin-guide/content/indicators).

::: tip Recommended order
If you are new to NADA, complete the [microdata](./microdata) tutorial first so you are familiar with login, publishing, and drafts. Then return here for indicators.
:::
