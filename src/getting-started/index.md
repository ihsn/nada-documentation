# Getting started

If you have just installed your NADA catalog and want to try publishing content, start with one of the short tutorials below. Sample files for the microdata walkthrough are available from our GitHub repository.

To use the API examples, install the R package **NADAR** or the Python library **PyNADA**. See [API tools](/admin-guide/api-tools) under [API & automation](/api-guide/).

## Choose a data type

| Tutorial | What you will publish |
|----------|------------------------|
| [Microdata](./microdata) | A survey microdataset with related resources (UI and API) |
| [Documents](./documents) | A document entry created from scratch in the admin UI (and via API) |
| [Indicators & time series](./indicators) | How to get started with indicators (admin UI + full guide) |
| [Geospatial](./geospatial) | How to publish geographic datasets (API-first) |

After these tutorials, use the [Content guide](/admin-guide/content/) for the full reference by data type, [Site administration](/admin-guide/web-ui/) for site settings, collections, and users, and [API & automation](/api-guide/) for NADAR/PyNADA and API examples.
