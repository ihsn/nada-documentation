# Site logs

Site logs record administrative actions taken within NADA — entries being added, edited, published, or deleted; user account changes; collection and settings modifications. They provide an audit trail for catalog management activity.

## Accessing site logs

Go to **Reports → Site logs** in the administrator menu.

## What is logged

Site logs capture events such as:

- Catalog entries created, edited, published, unpublished, or deleted
- User accounts created or modified
- Collection changes
- Settings changes

Each log entry records the event type, the affected record, the user who performed the action, and a timestamp.

## Exporting logs

Logs can be exported for archiving or external analysis. Use the export function to download log data in a structured format.

## Log retention

Log entries accumulate over time. Review and archive old logs periodically to manage storage size.
