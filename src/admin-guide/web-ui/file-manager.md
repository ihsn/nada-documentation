# File manager

The file manager provides access to the public file storage (`files/public`) where downloadable documents, images, and other resources are stored. Files uploaded here are publicly accessible from the catalog.

## Accessing the file manager

Go to **Settings → File manager** in the administrator menu.

## Browsing files

The file manager displays all files in the public filestore with their name, type, size, and upload date. Use the search box to filter by filename or type. Files can be sorted by name, date, or file type.

## Uploading files

1. Click **Upload**.
2. Select one or more files from your computer.
3. Upload progress is shown for each file.

::: info Screenshot
_Add screenshot: File upload dialog with progress indicator_
:::

Uploaded files are immediately available at their public URL.

## Deleting files

Select one or more files using the checkboxes and click **Delete**, or use the delete icon on an individual file. Deleting a file removes it permanently from the server — ensure it is not referenced in any catalog entries before deleting.

## Notes

- Only files in the `files/public` directory are shown here. Files attached to catalog entries as study resources are managed through the catalog entry editor.
- The file manager is intended for static assets such as documentation pages, site images, and similar shared resources.
