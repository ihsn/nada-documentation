# Bulk data access

Bulk data access allows administrators to group studies into collections that users can download as a package. This is useful when datasets are frequently requested together or belong to a related series.

:::

## Managing bulk access collections

Go to **Studies → Bulk data access** in the administrator menu.

The page lists all bulk access collections with the collection name, number of attached studies, and available actions.

## Creating a collection

1. Click **Add collection**.
2. Enter a title and description for the collection.
3. Optionally set a weight to control the display order.
4. Click **Save**.

## Attaching studies

After creating a collection, attach studies to it:

1. Open the collection from the list.
2. Click **Attach studies**.
3. Search for and select the studies to include.
4. Click **Save**.

## Editing and deleting

Use the **Edit** and **Delete** actions in the collection list to modify or remove a collection. Deleting a collection does not delete the studies — it only removes the bulk access grouping.

## User-facing access

When a bulk access collection is published, users can download all attached studies as a package from the catalog's public interface.
