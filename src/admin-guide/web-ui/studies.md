# Manage studies

The **Manage studies** page — accessible via **Studies → Manage studies** in the administrator menu — is the central listing of all catalog entries. From here you can add, edit, publish, unpublish, and delete entries across all data types.

## Filtering and searching

The studies list can be filtered by data type, collection, publication status (draft / published), and country. Use the search box to find entries by title or ID.

Select multiple entries to apply batch actions such as publish, unpublish, or move to a collection.

## Entry lifecycle

All catalog entries go through the same publishing lifecycle — draft, published, and archived — regardless of data type. See [Entry lifecycle](/admin-guide/content/lifecycle) for details on status transitions and visibility rules.
