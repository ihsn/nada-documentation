MCP server (AI assistants) ​

The Model Context Protocol (MCP) lets an AI assistant, such as Claude, use your catalog as a tool. Connected to NADA's MCP server, an assistant can search the catalog, read a study's metadata, and fetch and analyse indicator data: "rank countries by under-5 mortality in 2022", "is literacy correlated with GDP?".

The MCP server is part of NADA-AI. It is running as soon as NADA-AI runs; this page explains how to make it reachable, how to configure it and how to connect assistants.

Checklist ​

  1. Install NADA-AI: NADA-AI semantic search (Docker).
  2. For indicator analytics, set up MongoDB and upload indicator data.
  3. Check the endpoint on the NADA-AI host.
  4. Configure it in NADA-AI's .env.
  5. Publish it through a reverse proxy, and decide who may reach it.
  6. Connect an assistant.

Requirements ​

ComponentNotes
NADA-AIInstalled and running. See NADA-AI semantic search (Docker)
NADAReachable from NADA-AI at AI4DATA_METADATA_CATALOG_URL
MongoDBNeeded only for the indicator data and analytics tools. Without it, search and metadata still work. See MongoDB
Reverse proxyApache or nginx with HTTPS, to make /mcp reachable from outside the NADA-AI host
AI assistantAny MCP client that supports the streamable HTTP transport: Claude (claude.ai, Claude Desktop, Claude Code), VS Code, the MCP Inspector

What the assistant can see ​

The MCP tools call NADA's public API (/api/catalog/search, /api/catalog/{idno} and /api/timeseries/data/...), anonymously. They send no API key or cookie, so they see exactly what a visitor to the catalog sees: published studies only. An unpublished study answers as not found.

NADA-AI's own NADA API key (AI4DATA_METADATA_CATALOG_X_API_KEY) is used for indexing only and is never sent by the MCP tools.

  • The tools do not query NADA-AI's search index directly. Their catalog searches go through NADA, so they are semantic only when NADA's search engine is NADA-AI (see NADA-AI search). Otherwise they get NADA's database or Solr results.
  • Every tool is read-only.
  • Every data type can be searched and its metadata read. The analytics tools work on indicators (time series) only, and need the indicator's data loaded in MongoDB.
  • Variables and citations have no MCP tools.

1. Check the endpoint ​

The MCP server listens on the same port as the NADA-AI API, at /mcp. No setting turns it on. On the NADA-AI host:

bash
curl -s -X POST http://127.0.0.1:8020/mcp \
  -H 'content-type: application/json' \
  -H 'accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"check","version":"1"}}}'

The answer includes "serverInfo" with the server name. With the compose file from the installation guide, NADA-AI listens on 127.0.0.1:8020 only, so /mcp cannot be reached from other machines yet.

2. Configure it ​

Add these to NADA-AI's .env (in /opt/nada-ai with the installation guide), then restart: docker compose -f docker-compose.nada.yml up -d.

VariableDefaultPurpose
FASTMCP_STATELESS_HTTPfalseSet to true whenever a reverse proxy, a load balancer or more than one process sits in front of NADA-AI. Without it, clients lose their session between calls
NADA_MCP_CATALOG_NAMENADA catalogYour catalog's name, used in the tool descriptions the assistant reads, e.g. Kenya National Data Archive
NADA_MCP_SERVER_NAMENADA MCP ServerName shown in the assistant's list of connectors
NADA_MCP_TOOL_PREFIXnadaPrefix of every tool and prompt name. Lowercase letters, digits and underscores. Change it when an assistant connects to several catalogs, e.g. knbs
NADA_MCP_SEARCH_CATALOG_DESCRIPTIONunsetReplaces the description of the search tool entirely
NADA_MCP_GET_METADATA_DESCRIPTIONunsetReplaces the description of the metadata tool entirely
NADA_MCP_LOG_LEVEL, NADA_MCP_LOG_FILEINFO, unsetLogging

NADA_MCP_PORT and NADA_MCP_TRANSPORT apply only to the standalone server (below), not to /mcp.

3. Publish it through a reverse proxy ​

No authentication

/mcp has no authentication and no rate limit. The tools see only published content, but every call costs NADA requests. Decide who may use it:

  • only your organisation: allow your network's addresses at the proxy, or keep it on a VPN;
  • anyone: publish it openly, as you would the catalog itself, and watch NADA's load;
  • in between: put authentication in front of it at the proxy.

claude.ai and Claude Desktop connectors call the server from Anthropic's cloud, so for them /mcp must be reachable from the internet. Claude Code, VS Code and the MCP Inspector call it from the user's machine.

Apache ​

In the NADA-AI virtual host from the installation guide, the /mcp lines must come before the catch-all ProxyPass /, because Apache uses the first match:

apache
ProxyPreserveHost On
ProxyTimeout 300

ProxyPass        /mcp http://127.0.0.1:8020/mcp flushpackets=on
ProxyPassReverse /mcp http://127.0.0.1:8020/mcp

<Location "/mcp">
    # Remove to allow everyone
    Require ip 10.0.0.0/8
</Location>

ProxyPass        /    http://127.0.0.1:8020/
ProxyPassReverse /    http://127.0.0.1:8020/

flushpackets=on sends streamed answers to the client as they are written. Needs mod_proxy and mod_proxy_http.

To publish only /mcp and keep the rest of the NADA-AI API private, leave out the two ProxyPass / lines.

nginx ​

nginx
location /mcp {
    allow 10.0.0.0/8;   # remove both lines to allow everyone
    deny  all;

    proxy_pass http://127.0.0.1:8020/mcp;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_buffering off;
    proxy_read_timeout 300s;
}

Check from outside:

bash
curl -s -o /dev/null -w '%{http_code}\n' -X POST https://nada-ai.example.org/mcp \
  -H 'content-type: application/json' -H 'accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"ping"}'

Any answer other than 403, 404 or a connection error means the proxy reaches NADA-AI.

4. Connect an assistant ​

Replace the URL with your own.

claude.ai or Claude Desktop: Settings → Connectors → Add custom connector, then enter https://nada-ai.example.org/mcp. The server must be reachable from the internet.

Claude Code:

bash
claude mcp add --transport http nada https://nada-ai.example.org/mcp

VS Code (.vscode/mcp.json):

json
{
  "servers": {
    "nada": { "type": "http", "url": "https://nada-ai.example.org/mcp" }
  }
}

MCP Inspector, for testing: run npx @modelcontextprotocol/inspector, choose the Streamable HTTP transport and enter the URL.

Check that it works ​

  1. Ask the assistant to list the NADA tools. The 17 tools below should appear with your prefix.
  2. Ask it to "find indicators about poverty". It should call nada_search_catalog.
  3. Ask for data from one of the results, e.g. "rank countries by this indicator for the latest year". It should call nada_get_schema, then nada_rank.

Tools ​

All tool names start with NADA_MCP_TOOL_PREFIX (default nada).

Catalog ​

ToolWorks onWhat it does
nada_search_catalogAll data typesSearches the catalog by keywords and filters. The data type defaults to indicators (time series); the assistant asks for another type, e.g. survey or document, when needed
nada_get_metadataAll data typesFull metadata of one study, by idno

Indicator data ​

These need the indicator's data in MongoDB.

ToolWhat it does
nada_get_schemaThe indicator's data structure: columns and their roles (geography, time period, value, dimensions), and the time format. The assistant calls it before any analytics
nada_get_codelistThe codes and labels of one dimension, e.g. SEX: M, F, T, to filter the data correctly
nada_get_dataObservations, page by page, with filters

Indicator analytics ​

Computed by NADA-AI from the indicator's data. Each accepts filters on dimensions for disaggregated indicators.

ToolWhat it answers
nada_rankTop or bottom geographies by value for one period
nada_extremesHighest and lowest observation, across all geographies and periods
nada_compareSide-by-side time series of several geographies
nada_summarizeMinimum, maximum, mean, median and standard deviation across geographies for one period
nada_growthChange between two periods per geography, absolute and in percent
nada_trendLinear trend per geography: slope, R² and direction (improving, declining, stable)
nada_coverageData availability per geography: periods covered and gaps
nada_outliersGeographies whose value is unusual for a period (Z-score)
nada_benchmarkWhere one or more geographies stand among all others: percentile, Z-score, distance from the mean
nada_aggregateGroup statistics per period, e.g. for a region or a custom group of countries
nada_correlateCorrelation between two indicators across geographies for one period
nada_joinTwo indicators merged by geography and period, for further analysis

Standalone server ​

The MCP server can also run on its own, without the NADA-AI API, for example on another host. It reads the same .env and only needs to reach NADA:

bash
uv run python -m nada_ai.mcp_server --port 8025

It always runs stateless. Publish it through a proxy as above, pointing at port 8025.

Troubleshooting ​

IssueWhat to check
The client cannot connect, or loses its session between callsFASTMCP_STATELESS_HTTP=true is missing behind the proxy. Add it and restart NADA-AI
Answers arrive only at the end, or time outThe proxy buffers. Use flushpackets=on (Apache) or proxy_buffering off (nginx)
404 from the proxyThe /mcp lines come after ProxyPass / (Apache), or the location is missing
claude.ai cannot add the connector/mcp is not reachable from the internet, or the certificate is not valid
Searches find no surveys or documentsThe search tool defaults to indicators. Ask for the data type in the question
Search results are not semanticNADA's search engine is not NADA-AI. See NADA-AI search
A study is "not found"It is unpublished. The tools see only published studies
Indicator data tools failThe indicator has no data in MongoDB, or MongoDB is not configured. Run php index.php cli/mongo_check on the NADA server
Tool calls fail with connection errorsNADA-AI cannot reach NADA at AI4DATA_METADATA_CATALOG_URL. From Docker, a NADA on the same server is http://host.docker.internal/...
A call is rejected before it runsNADA-AI's input check blocked it: an argument over 5,000 characters, a search under 3 characters, or text that looks like a prompt injection
